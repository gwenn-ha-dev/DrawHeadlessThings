DrawHeadlessThings

The draw-things-community image-generation engine, without the app around it: one process that serves a REST API and an MCP endpoint, so scripts and AI agents can generate, edit and chain images.

Download for macOS Source on GitHub

Free and open source (GPL-3.0-or-later) · macOS 14 or later, Apple Silicon · signed and notarized

Why DrawHeadlessThings

Three verbs over HTTP

compose, edit and restore, described by an OpenAPI 3.1 spec, with Swagger UI at /docs.

MCP for AI agents

The same surface over the Model Context Protocol (Streamable HTTP), one tool per route, in the same process.

Reproducible

No sessions, no gallery. Every response carries X-DHT-Recipe, the canonical recipe that produced the bytes.

Dry-run first

/v1/resolve/{verb} reports defaults, warnings and a compute estimate without touching the GPU.

Pipelines

/v1/pipeline chains verbs: a step's output feeds a later step through a $name reference.

Models on demand

The official and community catalogs are listed, and base models install with POST /v1/assets/install.

One request

With the server on localhost:7766:

curl -X POST http://localhost:7766/v1/compose \
  -H 'content-type: application/json' \
  -d '{
        "model": "z_image_turbo_1.0_q8p.ckpt",
        "prompt": "a misty forest at dawn, cinematic",
        "params": { "width": 1024, "height": 1024, "steps": 8 }
      }' \
  | jq -r '.images[0]' | base64 -D > forest.png

The JSON also carries the seed, the generation time and the defaults the server applied. The same body posted to /v1/resolve/compose is a dry run.

Safe by default

defaultLoopback only, no token: a trusted local machine.
--bind publicServes the LAN and requires --token. No TLS: put a reverse proxy in front if you need one.
--read-onlyRefuses every asset install or deletion.
--max-active-runs NCaps concurrent generations.

Get it

Download the .dmg Read the README

Open the .dmg, drag DHTServer onto Applications. It is signed with a Developer ID and notarized by Apple: it opens with a double click. DHTServer is a menu-bar agent that runs the server; point it at your models folder in Settings. Headless? Run dht-server from the app bundle, or build it from source.
